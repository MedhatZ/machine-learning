# محلل البورصة المصرية (Poesa)

أداة ترتيب وتحليل لأسهم من دائرة **EGX 30**. الحسابات (الدرجة، الباك تست، دفتر التوقعات) تتم محليًا في بايثون. النموذج اللغوي يكتب تقريرًا عربيًا من الأرقام الجاهزة فقط، ولا يغيّر الترتيب ولا الأوزان.

الناتج مساعدة على التحليل، مش توصية شراء أو بيع.

## المتطلبات

- Python 3.11+ مستحسن
- اتصال إنترنت لأول تنزيل من Yahoo Finance (بعدها الكاش المحلي يكفي لفترة)

## التثبيت

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

املأ المفتاح في `.env` لو هتستخدم التقرير العربي. الملف `.env` مستبعد من Git عمدًا.

تشغيل سريع:

```powershell
python cli.py scan
streamlit run app.py
```

الاختبارات (من غير شبكة):

```powershell
python -m unittest tests.test_core -v
```

## أوامر CLI

| الأمر | الوظيفة |
| --- | --- |
| `python cli.py scan` | رتّب الأسهم اللي عدّت فحص الجودة |
| `python cli.py scan --save` | نفس المسح + احفظ لقطة أعلى 5 |
| `python cli.py scan --refresh` | تجاهل الكاش ونزّل من جديد |
| `python cli.py scan --report` | أضف تقريرًا عربيًا من النموذج |
| `python cli.py analyze COMI` | تفاصيل سهم واحد |
| `python cli.py compare COMI HRHO ETEL` | قارن من سهمين لأربعة |
| `python cli.py backtest` | ووك-فورورد: Rank IC والشرائح التاريخية |
| `python cli.py journal save` | احفظ لقطة اليوم في الدفتر |
| `python cli.py journal list` | اعرض اللقطات المحفوظة |
| `python cli.py journal review` | راجع اللقطات بعد 20 جلسة تداول |
| `python cli.py journal status` | هل العيّنة المتقيّمة كافية للتعلم؟ |
| `python cli.py journal autopsy` | تشريح اللقطات الغلط (امتداد / MA50 / زخم) |
| `python cli.py journal rules propose` | سجّل فرضية فلتر MA50 مجمّدة |
| `python cli.py journal rules list` | اعرض القواعد المجمّدة |
| `python cli.py journal rules eval <id>` | قيّم قاعدة على لقطات بعد تاريخ التجميد فقط |

`--report` يحتاج المفتاح في `.env`. لو فشل المزود الأساسي أو الموديل غير متاح، النظام بيحوّل تلقائيًا لموديل احتياطي (`deepseek-v4-flash`).

## المنهج

درجة توقع **20 جلسة** بأوزان ثابتة في `poesa/config.py`:

| العامل | الوزن |
| --- | ---: |
| زخم قصير | 30% |
| قوة نسبية | 25% |
| اتجاه | 20% |
| حجم واختراق | 15% |
| مخاطر | 10% |

- البعد عن MA50 وMA200 بيخصم لحد 25 نقطة، ومش بيزوّد الدرجة.
- الأوزان **مش بتتظبط** عشان ترتيب يدوي معيّن ولا عشان نتائج أول شهر من الدفتر.
- الباك تست بيستخدم عضوية EGX30 المعلنة في كل تاريخ، ويقيس Rank IC على آفاق متعددة وشرائح اقتصادية ثابتة. النتيجة مش بتغيّر الأوزان.
- خط الأساس الرسمي `^CASE30` لو تاريخه كافي؛ غير كده القوة النسبية ضد متوسط باقي القائمة (leave-one-out).
- تكلفة الجولة الكاملة افتراض معلن 0.8%.

تفاصيل إضافية تظهر من `poesa.config.methodology_lines()`.

## دفتر التوقعات والتعلم

1. كل يوم فيه جلسة جديدة على ياهو: `journal save` (متكررش نفس تاريخ الجلسة).
2. بعد **20 جلسة تداول** (مش 20 يوم تقويم): `journal review` يعلّم اللقطة صح لو متوسط أعلى 5 سبق متوسط باقي المرتبة وقت الحفظ.
3. بعد **8 لقطات متقيّمة على الأقل**: `journal autopsy` يشرّح الغلط (امتداد، شريحة MA50 −5%..0، زخم/RS، سحب من اسم واحد).
4. لو ظهر نمط: `journal rules propose` ثم لاحقًا `rules eval` على اللقطات **بعد** تاريخ التجميد فقط. ممنوع تدوير `WEIGHTS` على عيّنة صغيرة.

اللقطات تتخزن في `data/journal/{YYYY-MM-DD}.json`. القواعد المجمّدة في `data/learn/rules.json` (محلية ومستبعدة من Git).

## ملاحظات قبل الرفع على Git

- لا ترفع `.env` ولا أي مفتاح API.
- لا ترفع `.venv/` ولا `data/cache/`.
- اللقطات في `data/journal/` اختيارية: مفيدة لو حابب تتابع نفس الدفتر بين الأجهزة.
- بعد الكلون: انسخ `.env.example` إلى `.env`، ثبّت المتطلبات، شغّل `scan` مرة عشان يتبني الكاش.

## إخلاء مسؤولية

الأسعار من Yahoo وقد تتأخر أو تنقص رموز. التنفيذ على سعر الإغلاق مش مضمون، خصوصًا أيام حدود الجلسة. استخدم الأداة للتحليل فقط.
